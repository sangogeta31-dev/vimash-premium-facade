# Vimash Prime Design

Design a premium, modern, and highly interactive website UI for Vimash Manufacturing Pvt. Ltd., a commercial Atta and Masala Pulverizer machine manufacturer. Create only the frontend UI/UX with no backend or functionality. The design should feel like a premium industrial brand rather than a traditional machinery website, using a clean layout, bold typography, smooth animations, modern cards, subtle gradients, glassmorphism where suitable, and plenty of white space. The website should include Home, About, Products, Manufacturing, Gallery, and Contact pages. On the Products page, organize the machines into two categories: Atta Pulverizers and Masala Pulverizers, each with 5 HP, 7.5 HP, 10 HP, 15 HP, 20 HP, and 30 HP models displayed as elegant product cards. Use a modern color palette with deep blue, white, charcoal, and orange accents. Add premium hover effects, scroll animations, a sticky navigation bar, floating WhatsApp and Call buttons, and a clean responsive layout. The overall website should look comparable to a high-end manufacturing company like Siemens, ABB, or Caterpillar, with a strong focus on professionalism, trust, and lead generation rather than an old-style industrial catalogue.
